# Вариант 3. Последовательность чисел

Порядок сдачи — в `ИНСТРУКЦИЯ.md`. Ниже — что должна делать программа.

Файл `data.yaml` содержит набор списков целых чисел. Для каждого списка нужно найти самую длинную **строго** возрастающую непрерывную серию, самую длинную **строго** убывающую, самую длинную серию одинаковых чисел (при равной длине — левую; один элемент — серия длины 1), непрерывный фрагмент с **максимальной суммой** (если все числа отрицательные — самое большое из них), число строгих локальных максимумов (элемент больше обоих соседей, края не считаются) и самое частое число (при равной частоте — меньшее по значению) вместе с его позициями (с нуля).

В самом конце выводится случай с наибольшей максимальной суммой (при равенстве — с меньшим номером).

Сумма фрагмента считается за один проход (алгоритм Кадане): в каждой точке выбирается, продолжить текущий фрагмент или начать новый с этого числа.

## Примеры

Вход:

```yaml
cases:
  - [1, 2, 3, 2, 1]
  - [-1, -2, -3]
  - [3, 3, 3, 3]
  - [4, -1, 2, 1]
```

Ожидаемый вывод:

```text
|   line | sequence      | increasing   | decreasing   | equal      |   max_sum | fragment      |   local_maxima |   mode | mode_at    |
|--------|---------------|--------------|--------------|------------|-----------|---------------|----------------|--------|------------|
|      1 | 1, 2, 3, 2, 1 | 1, 2, 3      | 3, 2, 1      | 1          |         9 | 1, 2, 3, 2, 1 |              1 |      1 | 0, 4       |
|      2 | -1, -2, -3    | -1           | -1, -2, -3   | -1         |        -1 | -1            |              0 |     -3 | 2          |
|      3 | 3, 3, 3, 3    | 3            | 3            | 3, 3, 3, 3 |        12 | 3, 3, 3, 3    |              0 |      3 | 0, 1, 2, 3 |
|      4 | 4, -1, 2, 1   | -1, 2        | 4, -1        | 4          |         6 | 4, -1, 2, 1   |              1 |     -1 | 1          |

Best case: 3, max_sum = 12
```

## На что обратить внимание

- Если скрипт падает при запуске — изучаем сообщение об ошибке и traceback.
- Если вывод оказался неправильным — запускаем программу в пошаговом режиме и проверяем текущий фрагмент суммы и словари частот
- Убедитесь, что для всех строк файла скрипт работает правильно
